# support_ticket_analyst
A tiny tool that has an AI assistant analyze and understand the support tickets.

# Table of Contents

# Technologies Used
OS: Windows 10
Anaconda
Python 3.10
Postgresql

# Usage
1. To create anaconda environment, run the command: conda create -p D:\coding_tests\flowtel\support_ticket_analyst\venv python=3.10
2. Activate conda environment: conda activate D:\coding_tests\flowtel\support_ticket_analyst\venv
3. Open pgadmin
4. Run the sql script inside the db folder.
